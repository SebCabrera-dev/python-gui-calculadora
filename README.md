# Calculadora Gráfica en Python (Tkinter)

Aplicación de escritorio con interfaz gráfica interactiva desarrollada en Python y Tkinter, con diseño oscuro y soporte para operaciones aritméticas y avanzadas.

## 🚀 Características
- **Interfaz Gráfica Responsiva:** Diseñada con Tkinter en layout Grid.
- **Operaciones:** Suma, resta, multiplicación, división, potencias y raíz cuadrada.
- **Manejo de Excepciones:** Control de división por cero y expresiones matemáticas inválidas mediante cuadros de alerta (`messagebox`).
- **Arquitectura POO:** Código estructurado en clases para facilitar mantenimiento y escalabilidad.

## 🛠️ Tecnologías
- **Lenguaje:** Python 3
- **GUI Framework:** Tkinter
- **Módulos:** `math`
